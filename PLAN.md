# PLAN.md — план сборки Quiz «Какая ты кофейня?»

## Видение

Одностраничный квиз: приветствие → 7 вопросов (по 4 варианта, каждый вариант
начисляет балл одному из 5 типов кофе) → экран результата «Ты — [тип кофе]!»
с описанием, рекомендацией и кнопкой «Пройти ещё раз». Дизайн тёплый,
кофейный, адаптивный.

## Типы кофе-результатов

1. Эспрессо — энергичный прагматик
2. Флэт Уайт — сдержанный эстет
3. Раф — домашний уют
4. Американо — минималист
5. Матча-латте — спокойный исследователь

Каждый из 7 вопросов даёт 4 варианта, каждый вариант указывает на один из
типов; итог — максимум совпадений, при ничьей — приоритет по порядку типов.
