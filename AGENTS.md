# AGENTS.md

## О проекте

Quiz-приложение «Какая ты кофейня?» — итоговая работа Модуля 2 курса.
Пользователь отвечает на 7 вопросов и получает тип кофе с описанием и рекомендацией.

## Стек технологий

- React 19 + TypeScript (strict)
- Vite — сборка и dev-сервер
- Чистый CSS (без UI-библиотек)

## Структура папок

- `src/data/` — вопросы и типы кофе (данные отделены от логики)
- `src/components/` — экраны и компоненты
- `src/App.tsx` — машина состояний: welcome → quiz → result
- `src/styles.css` — все стили, палитра кофейни в `:root`

## Команды для разработки

- `npm run dev` — dev-сервер
- `npm run build` — production-сборка (обязательна перед деплоем)
- `npm run typecheck` — строгая проверка типов
- `npm run preview` — предпросмотр production-сборки

## Соглашения по стилю кода

- Без комментариев в коде; описания — в README.md
- Самодокументируемые имена, данные в `src/data` типизированы
- Один коммит — один осмысленный шаг (пункт требования)
